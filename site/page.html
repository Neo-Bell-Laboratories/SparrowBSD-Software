SYSTEM NOTES / DEVELOPMENT STATUS

The system,
as it stands.

SparrowBSD is an experimental operating system with a native kernel and C userland. It is not a FreeBSD binary-compatible distribution.

Platform
AArch64, targeting Raspberry Pi Zero 2 W. QEMU is the current automated validation environment; physical Pi drivers remain in progress.
Runtime
Newlib, static native ELF binaries, directory and file APIs, signals, process groups, PTYs, and Unix-domain stream sockets.
Userland
Upstream dash, tmux, Vifm, nvi, SQLite, awk, sed, and sbase utilities. Vifm file operations run synchronously while native threads remain pending.
Storage
Extended V7-style filesystem with long names, sparse files, metadata and a 500 MB individual-file limit. NTZ integration is still under development.
Packages
The native pkg tool currently builds trusted local source ports. Remote package installation and system-update transactions are not enabled by this website.

Follow the source.

Release publication happens in the official software repository. Packages and ports appear here only when their assets are published in a stable official release.
